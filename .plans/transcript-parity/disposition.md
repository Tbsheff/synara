# Transcript parity: event disposition

One row for each Codex event (113: 19 items, 84 notifications without `item/started` and `item/completed`, 10 requests) and each Claude row (109: §A–§E without the `tool_use` pointer row). Event names and grades come from `codex-synara-mapping.md` and `claude-synara-mapping.md`. The table is generated by a script that asserts both counts.

Build plan and file owners: [plan.md](plan.md). Payload fields: `packages/contracts/src/transcriptDetails.ts`.

## Rules applied

| Rule | Effect |
|---|---|
| High-volume state stays off the transcript | token usage, context window, rate limits, `task_progress`, goal, environment and safety buffering go to `surface:` |
| Compact deliberate rows, never a bare method name | hooks, skills, MCP status, config/deprecation warnings, review mode, refusals, hook blocks, local command output, notifications, tool-result images, server-tool results become `transcript.notice` rows or typed tool rows |
| `drop:` only for plumbing or APIs Synara never calls | each gated Codex method gets an explicit ignore entry in `codexMethodDispositions.ts`; it never falls through to `event.unmapped` |
| Reasoning | rows stay (user wants all events). Codex reasoning becomes live. The latest summary heading replaces "Thinking" in the working-status line |
| Repeats | every notice has a `dedupeKey`; the projection upserts one activity per key, so repeats update a row instead of adding rows |

## Legend

Owner: `W1/` = Wave 1 server agent, `W2/` = Wave 2 web agent (see [plan.md](plan.md)). Notice rows list the full chain: the adapter emits a `transcript.notice` runtime event → W1/S-core projects it to a `transcript.notice` activity (id from `dedupeKey`) → W2/W-timeline derives the work-log entry → W2/W-rows renders it in `TimelineWorkEntryRow`. "-" = no change needed.

Notice titles: `title` is Synara-composed. When it contains provider text, the producer trims it, caps it at 200 chars, and falls back to a fixed label when empty; longer provider text goes in `detail` or `body`.
