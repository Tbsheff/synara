Design principles

  1. One card per spawn call, at the spawn point. State changes update the card in place. The transcript gets no "Moved to background", "Subagent finished", or "N updates" rows.
  2. Compact group header uses the tool-row shell: "Running 3 agents · 1:12", then "Running 1 of 3 agents · 2:41 · 1 failed", then "Ran 3 agents · 6:03". One agent reads "Running 1 agent" (Codex: "Created an agent").
  3. Progress line is the latest provider summary, else "Using <tool>". It is never the task description again.
  4. Status is the only hue (subagentPresentation.ts): a dot, status text tinted only when Running or Failed, and a tabular elapsed time.
  5. On completion, the row keeps a two-line result or error preview. Expand the row for the full detail and "Open thread".
  6. Wake turns are their own response, with a quiet marker. The final reply is never folded.
  7. All new chrome uses text-ui* sizes. Motion uses DisclosureRegion / DisclosureChevron (220 ms ease-out, reduced-motion safe).

Open questions

  1. Reverse a design decision. isRoutedSubagentWorkEntry says "the transcript never renders a subagent roster". This proposal renders one card per spawn. Is that change approved?
  2. Strip and card duplication. Should the strip compact to its header while the card is on screen (IntersectionObserver), or stay as it is?
  3. Wake marker. Use a quiet divider (proposed), a Codex-style "{name} finished" row, or nothing?
  4. Sizing. Transcript tool rows size from the chat font prop (textFontSizePx), but the card uses text-ui* as asked. These differ when the chat and UI font sizes differ. Which one should the card follow?
  5. Enable agentProgressSummaries for model-written progress lines? This costs extra tokens per agent.
  6. Nested subagents (an agent's own background tasks). Show them only in the child thread? Today they leak into the parent's "Moved to background".
  7. Light mode: the -300 status hues have low contrast on white. Use -500 in light?
  8. In a settled turn, should the card be lifted out of "Worked for" (shown here) or stay inside the fold?
  9. Default open state: open while any agent runs, closed when all settle? (Codex multi-agent-action rows are collapsible.)
